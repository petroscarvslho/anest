TEMPLATE HEMOBA - INSTRUÇÕES DE INSTALAÇÃO
============================================

A ficha HEMOBA (Solicitação de Transfusão de Hemocomponentes) foi integrada ao
Prontuário de Anestesia. Para usar a funcionalidade de geração de PDF HEMOBA,
você precisa copiar o arquivo do template PDF.

PASSOS:
1. Obtenha o arquivo HEMO.pdf (Solicitação de Transfusão STH Rev.5)
2. Copie o arquivo para esta pasta (public/)
3. Renomeie para: hemoba-template.pdf

LOCALIZAÇÃO:
- Origem: Seu template HEMOBA ou Google Drive
- Destino: public/hemoba-template.pdf

DEPOIS DE COPIAR:
- O app reconhecerá automaticamente o template
- A função "HEMOBA" estará disponível na tela do formulário
- Clique no botão "HEMOBA" para abrir o formulário de preenchimento
- Clique em "Gerar PDF HEMOBA" para fazer o download

O template deve ser um PDF A4 com espaço em branco onde os dados serão sobrepostos.
